# customer-support-api-automation
A Python project demonstrating API integration and automated customer support ticket processing.
## How I Created This Project

1. Created a Python script for customer support automation.
2. Connected the script to a public API using the Requests library.
3. Retrieved customer information from the API.
4. Checked the API response to make sure the request was successful.
5. Displayed customer names, email addresses, and company information.
6. Documented the project and committed the code to GitHub.
